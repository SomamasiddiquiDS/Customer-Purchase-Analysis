## 1. Project Overview

Customer Purchase Analysis is an end-to-end SQL data analytics project designed to analyze customer purchasing behavior, revenue distribution, and sales performance.

The project uses MySQL to explore a dataset containing 500 customer records. SQL queries are used to transform raw customer data into meaningful business insights that can help businesses understand customer segments, purchasing patterns, and revenue trends.

## 2. Business Problem

Businesses need to understand their customers and purchasing patterns to make better decisions.

This project focuses on answering important business questions:

- Which cities generate the highest revenue?
- Which customer segments contribute the most to sales?
- Which payment methods are most commonly used?
- Which age groups have higher purchasing activity?
- How does revenue change over time?
- Who are the highest-spending customers?
- Which days have stronger purchasing activity?

## 3. Dataset Description

The dataset contains 500 sample customer purchase records with the following columns:

| Column | Description |
|---|---|
| customer_id | Unique customer identifier |
| customer_name | Customer name |
| age | Customer age |
| city | Customer location |
| monthly_income | Monthly customer income |
| purchase_amount | Customer purchase value |
| order_date | Purchase date |
| payment_method | Payment method used |
| customer_segment | Customer category |

**Dataset Type:** Synthetic sample data created for educational and portfolio purposes.
